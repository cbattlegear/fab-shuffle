Sign in with a service principal

Credentials stay in this container's memory and are never written to disk. The service principal needs Reader on the target capacity and Admin on the source workspace.

Pick the target capacity

The new workspace is created on this capacity, which determines the target region.

Unfinished migrations

These stopped partway, most likely because the container was restarted. Picking one up carries on from where it got to instead of building the workspace again.

    Leftover scratch workspaces

    Earlier runs did not finish cleaning up. These hold only temporary Copy Jobs.

      Locked out of a workspace Fab Shuffle created?

      A run that failed before its permissions step leaves a workspace only the service principal can see. Copy the admins of the source workspace onto it to get back in. This only grants access, never removes it.

      Pick the source workspace

      Everything Fab Shuffle supports is recreated in a brand new workspace. The source is left untouched.
